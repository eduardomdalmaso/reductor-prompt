## Limitações Conhecidas (v1.0.0)

1. **Granularidade do dataset rotulado (Rodada 18):** as 25 perguntas avaliaram relevância em nível de **livro** (`book_title`), não precisão em nível de chunk ou página específica.
2. **Concorrência de cache em processo separado (Rodada 18):** o teste de estresse concorrente do `EmbeddingLRUCache` (20 workers, 60 tarefas com `invalidate()`) rodou em processo Python direto, enquanto os benchmarks HTTP frio/quente rodaram sequencialmente.
3. **Soak pós-refatoração:** após a modularização (Rodada 14) foi executado soak de 5 minutos (`300.66s`); o soak completo de 60 minutos foi homologado na arquitetura imediatamente anterior (Rodada 13).
